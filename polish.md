# UI / VFX / art polish workflow

1. Inspect project genre, existing visual language, current UI/3D assets and target devices.
2. Identify one unifying art direction: shape, typography, color, motion grammar, silhouette, sound.
3. Build only 2–3 primary feedback layers; reduce competing ornament.
4. Implement responsive safe-area aware layouts, gamepad/touch/focus and reduced-motion option.
5. For effects: anticipate -> contact -> decay, server-authoritative event + client cosmetic replication, bounded pooling and device tiers.
6. Review at true game camera distance, crowded scene, bright/dark environments, mobile and desktop resolution.
7. If available capture before/after Studio screenshots and verify actual visual result; otherwise describe manual screenshots to compare.

Never claim a visual design is proven from code only. Avoid unsupported render APIs and assets that are not owned by the project.
