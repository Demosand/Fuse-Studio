# Retention without dark patterns and progression math

## Player motivation
Strong core action is fun without an external reward. Build 10-second sensory loop, 3-minute goals, session milestone and return reason. Use motivation derived from mastery, social play, discovery and collection; not manipulative guilt or misleading scarcity.

## Economy model
Map every currency faucet and sink, time-to-unlock, visible impact of upgrades, soft/hard caps, and potential inflations. Do a spreadsheet or numerical simulation before adding rebirth. Rewards should track skill/progression, not only random rolls. Document server authority for all purchases, exchange rates and transaction logs.

## Observe and iterate
Onboarding completion, time to first satisfying action, long-tail goals, drop-off points, repeat sessions and player feedback. Metrics without ethical interpretation can encourage harmful loops; explicitly guard against confusing time spent with wellbeing. Mark speculative predictions as hypotheses.
