# Coverage and design choices

| Upstream area | Kira Studio 2.0 integration | Extension beyond original emphasis |
|---|---|---|
| ro-engineer strict Luau, architecture, ECS/OOP, cleanup | Core router + engineering references | Security threat model, network predictions, long-lived GUI lifecycle, code examples |
| ro-engineer game loop, progression/economy | Gameplay + operations + design workflows | Ethical incentive guardrails and measurable test plans |
| ro-engineer Studio/ROTEX adaptive workflows | Project modes, studio specialist | Backup/edit safety, source/Rojo workflow and explicit honest tool reporting |
| roblox-brain scripting knowledge, DataStores, NPC | Engineering/gameplay references, examples | Migrations, idempotency, server-side rewind, Parallel Luau, profiling |
| roblox-brain UI and modeling | UI Expert references, UI Director skill | Design tokens, motion state machines, gamepad/touch/localization, quality scorecard, material recipes |
| roblox-brain VFX, animation, lighting | VFX Expert & creative skill | VFX LOD/quality tiers, shot direction, camera comfort, audio mix contracts |
| roblox-brain knowledge server | Local Node stdio search | Russian aliases, area filter, chunked reading, no sharing/telemetry |

This is **not** a claim of 100% verbatim content parity: Kira Studio is a curated original integration and expansion, not a fork that tracks every upstream file. It also is not proof that Kira produces better generated projects. Coverage must continue to be benchmarked.
