# Safe Stud UI starter

This example is a Roblox **LocalScript** under StarterPlayerScripts, not runnable from Node.js. It demonstrates how to consume the upstream MIT Stud kit with Fuse-native safe adapters, natively drawn basket/gamepad icons, missing banana replacement and product rarity panel.

Place seven ModuleScripts in ReplicatedStorage: StudUI, StudMotion, CheckUIIcons, StudAssetGuard, StudUISafe, StudIconsSafe and StudNativeIcons. Avoid executing the source's old demos without migration if their project includes reported inaccessible image IDs.

Use the demo only for styling: it does not grant rewards or charge money. Verify interaction and frame counts in Roblox Studio, test mobile and gamepad. Clean it up after test; Fuse did not run it in Roblox Studio.
