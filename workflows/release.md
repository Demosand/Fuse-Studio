# Release readiness workflow

- Verify core loop, save, purchases, joins/leaves, respawns, translations and failure handling.
- Security audit critical remotes, DataStore session ownership, receipt idempotence, exploit spam.
- Test Studio multi-client, low-spec mobile, gamepad, production-like network latency and full server load.
- Check resources: assets, audio licensing, Roblox policy changes, privacy, age requirements, paid randomness disclosures.
- Backup place and source; stage migrations; plan code/data rollback and hotfix path.
- Release with monitoring plan: errors, loading failures, duplicate grants, unresponsive UI, memory trends.

Never mark complete when evidence is absent; hand the user a short list of remaining manual checks.
