# Inclusive presentation and interaction

A polished experience works with mouse, keyboard, touch and gamepad. Treat mobile as a first-class target when the Roblox audience needs it. Never encode critical meaning by color alone or make crucial UI readable only at 1080p.

## Input

- Check touch target size and thumb-reach; map primary actions consistently.
- Gamepad needs visible selection/focus, intuitive navigation and reliable back/cancel.
- Keyboard shortcuts should not be the only way to act. Don't override platform/system navigation carelessly.
- Input consumption should avoid conflicting with textboxes and core Roblox controls.

## Visuals

Adequate contrast, visual hierarchies, legible typography, icons with labels, safe-area alignment, obvious active/disabled states. Avoid excessive bloom/flashing, motion sickness camera swings and confusing transparent overlays.

## Options

Reduced camera shake/motion; particle quality; audio mix sliders; subtitles for essential dialogue; optional simplified UI. Save user preferences with reasonable defaults; test when settings migrate or user changes devices.

## Test matrix

Small phone in portrait/landscape when supported; tablet; 16:9 PC; ultrawide; gamepad focus; no audio; reduced motion; high latency; low quality level. This is a product acceptance test, not an optional cosmetic step.
